# nico skills

Skills written for the nico-agent loop. See ../../FORK.md.

- **[verdict](./verdict/SKILL.md)**: The Reviewer's Verdict on a PR, from a re-run of the repo's verification skill at its head.
- **[quality-scan](./quality-scan/SKILL.md)**: Audit a Repo with ponytail-audit and a deepening scan and file the top findings as issues, at most five open at once, without editing code. User-invoked.
- **[faux-nico](./faux-nico/SKILL.md)**: Answer an Asking Implementer from the Repo's PRODUCT.md, the issue and its parent, only when they settle the question.
- **[morning](./morning/SKILL.md)**: Write the Morning summary from nico-agent status since the last one: what to merge in which order, what needs the user, and what the night did.
